# Security policy

This project contains **only synthetic data** and no credentials. Personal-looking values (names, emails, phone
numbers, national ids) are generated and use the reserved `example.org` domain.

If you find real personal data, a real company name, a secret, or a vulnerability in the code, please **do not
open a public issue**. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/juansanchezalcantara20-ai/data-governance-as-code/security/advisories/new)
and it will be removed and the history rewritten if needed.

Supported version: the latest release on `main`.
