# KPI catalog fixture (project 2)

**English** · Español below

`catalog.yaml` is an offline copy of `kpis/catalog.yaml` from
[kpi-catalog-storytelling](https://github.com/juansanchezalcantara20-ai/kpi-catalog-storytelling)
(commit `67e3e37`, MIT licence, same author). It is a fixture: no network access is needed and it is not edited
here. `govkit` applies to it the same kind of checks it applies to its own glossary and contracts
(`src/govkit/kpi_catalog.py`); the results appear in the demo app as the domain "KPIs (project 2)".
